# TeaReasonable AI — DSS User Evaluation Questionnaire

Use this only after any required university ethics/approval process is satisfied. Do not collect names, phone numbers, email addresses, NIC numbers, or other unnecessary personal identifiers.

## Participant task protocol
1. Select one supported factory and generate the next-month Reasonable Price forecast.
2. Enter an expected green-leaf quantity and interpret estimated gross earnings.
3. Interpret the approximate prediction interval and reliability level.
4. Compare factories and identify the highest predicted Reasonable Price alternative.
5. Open one factory forecast and inspect its SHAP-based explanation.

Record Task 1–5 as Success / Not successful.

## System Usability Scale (SUS)
Rate each statement from 1 = Strongly disagree to 5 = Strongly agree.

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

## Research-specific 1–5 ratings
- Price forecast clarity
- Gross-earnings estimate clarity
- Prediction-range / uncertainty clarity
- Usefulness for planning and factory comparison
- Trust appropriateness (the system communicates limitations without overclaiming certainty)

## Optional comment

## Important interpretation
The system compares factories primarily using predicted Reasonable Price. It does not currently include transport cost, distance, quality deductions, contracts, acceptance rules, or other owner-specific operating conditions.
